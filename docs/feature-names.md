# Feature names

User-visible feature names and the result of their trademark check (craft-contrib `standards/naming.md`).
Unclear means no. A rename changes labels only and keeps command ids and stored values.

| Label | Checked on | Result | Notes |
|---|---|---|---|
| Mesh, Sprite, Camera, Directional Light, Transform, Tags | not yet | Not checked yet | Generic graphics terms; run the naming.md check before a release |
| Scene view, Hierarchy, Inspector | not yet | Not checked yet | Generic editor terms; same |
| Console, Project, Play mode, Scripts | not yet | Not checked yet | Generic terms; same |
| Agent control | not yet | Not checked yet | Status-bar label of the editor's control channel; same |

Command ids, preference keys, code and internal docs are not covered by this check.
